# Volca Sampler Multi Import

Unofficial personal-use modified build of the open-source `volca-sampler` project.

## Changes
- Multi-file audio import
- Starting Volca Sample slot prompt
- Automatic sequential slot assignment
- Existing upstream SYRO transfer workflow retained
